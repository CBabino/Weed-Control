How big is that lot?

Type an address in Maricopa County and this looks up the parcel boundary on file with the County Assessor, then measures it directly.

Street number + name is enough — city, unit, and ZIP are optional and ignored.

Source: Maricopa County Assessor's Office public parcel records, queried live from the county's own ArcGIS map service. Lot size is measured from the official parcel boundary geometry on file, not estimated.

Coverage is limited to Maricopa County, Arizona. Records can lag recent subdivisions or boundary adjustments — for anything official (title, permits, disputes), confirm with the Assessor's Office directly.
