How big is that lot?

Type an address in Maricopa County and this looks up the parcel boundary on file with the County Assessor, measures it directly, then subtracts the actual building footprints on the lot (from OpenStreetMap) to estimate treatable acreage.

Street number + name is enough — city, unit, and ZIP are optional and ignored.

Source: Maricopa County Assessor's Office public parcel records, queried live from the county's own ArcGIS map service. Lot size is measured from the official parcel boundary geometry on file, not estimated. Structure size is measured from OpenStreetMap building footprints on the lot; when OSM has nothing mapped there, it falls back to the Assessor's on-file interior living space as a rougher estimate.

Coverage is limited to Maricopa County, Arizona. Records can lag recent subdivisions or boundary adjustments — for anything official (title, permits, disputes), confirm with the Assessor's Office directly.
